# مشروع فاحص الروابط والبريد الإلكتروني

مشروع واحد بواجهتين:
- `desktop_app.py`: واجهة سطح المكتب باستخدام Tkinter.
- `app.py`: موقع ويب باستخدام Flask.
- `scanner.py`: محرك الفحص المشترك بين الواجهتين.

## 1) المتطلبات
- Python 3.10 أو أحدث.
- اتصال بالإنترنت اختياري أثناء التشغيل؛ يلزم فقط عند نشر الموقع أو تحميل خط Google Fonts.

## 2) التثبيت والتشغيل على Windows
افتح Terminal داخل مجلد المشروع ونفّذ:

```bash
py -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

تشغيل الموقع محليًا:

```bash
python app.py
```

ثم افتح المتصفح على: http://127.0.0.1:5000

تشغيل برنامج Tkinter:

```bash
python desktop_app.py
```

## 3) نشر الموقع على الإنترنت
يمكن نشر تطبيق Flask على خدمة استضافة تدعم Python (مثل Render أو PythonAnywhere).
- ارفع ملفات المشروع إلى مستودع Git.
- اجعل أمر التثبيت `pip install -r requirements.txt`.
- استخدم أمر تشغيل إنتاجي مثل `gunicorn app:app` على Linux، وأضف `gunicorn` إلى requirements عند الحاجة.
- عيّن متغير بيئة `SECRET_KEY` بقيمة عشوائية قوية.
- تأكد من استخدام HTTPS، وحدد سياسة خصوصية ومدة الاحتفاظ بالسجل.

## 4) حدود الفحص
هذه نسخة تعليمية أولية تعتمد على قواعد ومؤشرات نصية، ولا تزور صفحات المواقع أو تحلل ملفاتها أو تتحقق من سمعتها عبر قواعد بيانات خارجية. مستوى الخطورة تقديري وليس حكمًا قاطعًا. فحص البريد يتحقق من الصيغة فقط ولا يؤكد وجود صندوق البريد.

## 5) ملاحظات أمان قبل الإطلاق العام
- لا تستخدم `debug=True` في بيئة الإنتاج.
- أضف حماية من إساءة الاستخدام (rate limiting) وقيودًا على حجم المدخلات.
- لا تعرض سجلًا عامًا يحتوي على مدخلات المستخدمين؛ السجل الحالي محلي على الخادم ومشترك بين زوار النسخة المنشورة.
- أضف سياسة لحذف السجلات وعدم تخزين بيانات حساسة دون حاجة.
- لا تضف ميزة فتح الروابط آليًا على الخادم دون ضوابط SSRF قوية.
